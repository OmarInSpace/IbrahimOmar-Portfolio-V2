# Portfolio Ibrahim Omar

Struktur folder:

    index.html        kerangka halaman dan isi teks
    css/style.css     semua gaya (warna dan font ada di :root paling atas)
    js/main.js        animasi: loader, hero, scroll, skills, projects, kursor
    js/secret.js      page rahasia (kode, tirai, galeri foto/video)
    assets/foto.webp  foto tanpa latar

Cara membuka: klik dua kali index.html. Perlu internet karena font dan GSAP dimuat dari CDN.

Yang perlu diganti:
- index.html: nama proyek (cari "Warung Digital"), email (nama@email.com), tautan Instagram/GitHub/LinkedIn, dua paragraf About.
- index.html: angka skill ada di atribut data-v pada tiap kartu .card.
- js/secret.js: kode rahasia ada di SECRET_CODE (huruf kecil).
- css/style.css: ganti warna di bagian :root paling atas.

Catatan: CSS-nya CSS biasa, bukan Tailwind.
